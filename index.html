Projects

Governance & Policy Agent

2026

An explainable compliance system for the Agentic Microservices Prototyping (AMP) platform. It reads structured and unstructured policy documents, extracts governance rules, and evaluates compliance with confidence scoring, escalation logic, and full policy traceability - so every decision traces back to its source document. RAG with sentence-transformers + FAISS reached 90%+ retrieval accuracy on test documents.

  • Python
  • FastAPI
  • RAG · FAISS
  • OCR
  • Multi-agent AI

E-Commerce Data System - ETL Pipeline

Code

A complete data-engineering system: from raw CSVs (~127K rows each) to a live REST API. Designed a 3NF PostgreSQL schema (6 tables, composite keys, value checks), built a Python ingestion pipeline with dedup, referential-integrity enforcement, and dependency-ordered loading, then wrote window-function analytics and a composite index that turned nested loops into a hash join. Served via FastAPI, orchestrated with Docker Compose.

  • Python
  • PostgreSQL
  • SQLAlchemy
  • FastAPI
  • Docker

DocuChat - Document Q&A

Code

A full-stack app that lets users upload PDFs or text and ask questions answered from the document's actual content. React + TypeScript frontend with chat persistence; Python/FastAPI backend using LlamaIndex for ingestion, chunking, and embedding, and ChromaDB for semantic retrieval. Answers are grounded in the source, with an explicit fallback when a question falls outside its scope. Containerized with Docker.

  • React · TypeScript
  • FastAPI
  • LlamaIndex
  • ChromaDB
  • Docker

Mapping the Pulse of NYC's Businesses

Code

Analysis of NYC's "Love Your Local Business" dataset (1,877 records) to understand where and how small businesses cluster. Found Food & Beverage dominates (871 of 1,877), Manhattan CBs 1-3 are the densest zones, and 403 businesses lack websites - a concrete signal of who's hardest to reach online. Delivered as Tableau and Power BI dashboards for non-technical audiences.

  • SQL
  • Python
  • Tableau
  • Power BI
