AI / RAG

Governance & Policy Agent

2026
Challenge
Organizations need documents checked against policy, but real policy documents are unstructured - and a black-box yes/no answer isn't auditable.
Approach
Built OCR-enabled document processing and chunking pipelines, then Retrieval-Augmented Generation with sentence-transformers and FAISS for context-aware policy retrieval. Wrapped it in REST APIs with confidence scoring, escalation logic, and policy traceability.

Data Engineering

E-Commerce Data System - End-to-End ETL

2025 Code →
Challenge
Five raw CSVs of roughly 127,595 rows each - duplicates, orphaned foreign keys, and untyped timestamps, with no usable schema underneath.
Approach
Designed a 3NF PostgreSQL schema of 6 tables with a composite primary key on order items and value-level checks. Built a Python pipeline that dedupes, type-converts, filters orphaned rows, derives the sellers table, and loads in dependency order - then wrote CTE and window-function analytics on top and served it through a FastAPI REST layer.
Impact
Replaced a correlated subquery with a single-pass join plus a composite index, shifting the query plan from repeated nested loops to a hash join. The entire stack - Postgres, ingestion, and API - comes up with one Docker Compose command.
  • Python
  • pandas
  • SQLAlchemy
  • PostgreSQL
  • FastAPI
  • Docker
Full-Stack AI

DocuChat - Document Q&A System

2026 Code →
Challenge
People need answers from their own documents without the model quietly inventing facts that were never in the source.
Approach
React and TypeScript frontend with file upload and chat that persists across refreshes. Python and FastAPI backend parsing PDF and text, using LlamaIndex for ingestion, chunking, and embedding, and ChromaDB as the vector store for semantic retrieval.
Impact
Answers stay grounded in the uploaded document, with an explicit fallback response when a question falls outside its scope. Containerized with Docker.

Analytics & BI

Mapping the Pulse of NYC's Businesses

2025 Code →
Challenge
1,877 business records across 19 columns, with no clear picture of where or how small businesses actually cluster across the city.
Approach
SQL and Python analysis across category, borough, community board, and neighborhood - then translated the findings into Tableau and Power BI dashboards built for non-technical audiences.
Impact
Food & Beverage dominates at 871 of 1,877 businesses; Manhattan holds 34.2% and Brooklyn 31.3%, with Community Boards 1-3 the densest commercial zones. Surfaced 403 businesses with no website and 229 with no phone number - a concrete list of who is hardest to reach online.
  • SQL
  • Python
  • Tableau
  • Power BI
